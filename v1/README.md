# RRD-102 ESP32 FM Radio — v1

NodeMCU-32S + RDA5807(RRD-102) + SSD1306 OLED 之 FM 收音機

## 硬體清單

| 元件 | 數量 | 說明 |
|------|------|------|
| NodeMCU-32S (ESP32) | 1 | 主控核心 |
| RRD-102 V2.0 (RDA5807) | 1 | FM 收音機模組 (I2C + 音訊輸出) |
| SSD1306 OLED (128×64) | 1 | I2C 顯示螢幕 |
| PAM8403 音訊放大器 | 1 | 3W 立體聲 D 類功放 |
| 2 吋小喇叭 | 2 | 左右聲道 |
| 5KΩ 電位器 | 2 | 頻率 & 音量旋鈕 |
| 按鈕開關 | 2 | 操作按鍵 |
| TP4056 充電模組 | 1 | 18650 鋰電池充電 |
| MT3608 DC-DC 升壓模組 | 1 | 18650 3.7V → 5V |
| 18650 鋰電池 | 1 | 電源 |
| 自鎖開關 | 1 | 電源總開關 |

## 接線圖

### 電源

```
18650 (3.7V)
   │
   ▼
  開關
   │
   ▼
TP4056 充電模組
   │
   ▼
DC-DC 升壓模組 → 5V out
                  │
                  ▼
            ESP32 Vin (5V)
            PAM8403 VCC (5V)
```

> 注意：RRD-102 與 OLED 由 ESP32 的 3.3V pin 供電，**不可接 5V**。

### 主電路接線

| ESP32 腳位 | 連接對象 |
|-------------|---------|
| GPIO21 (SDA) | OLED SDA、RRD-102 SDA |
| GPIO22 (SCL) | OLED SCL、RRD-102 SCL |
| GPIO34 | 頻率電位器中間抽頭 |
| GPIO35 | 音量電位器中間抽頭 |
| GPIO19 | 上方按鈕 (另一端接 GND) |
| GPIO18 | 下方按鈕 (另一端接 GND) |
| 3.3V | OLED VCC、RRD-102 VCC |
| GND | 所有元件的 GND 共接 |
| Vin (5V) | DC-DC 升壓模組輸出 |

### 音訊

```
RRD-102 Audio OUT (L/R)
   │
   ▼
PAM8403 Input (L/R, 串聯 1~10µF 電容)
   │
   ▼
2 吋喇叭 (L/R, 左右各一)
```

> RRD-102 音訊輸出需要串聯電容 (隔直) 再接 PAM8403 輸入。
> 建議使用 1µF ~ 10µF 無極性電容。

## 功能說明

### 操作方式

| 動作 | 按鈕 | 功能 |
|------|------|------|
| 短按 | 上方 (Next) | 預設模式：上一個頻道 / 選單：向上 |
| 短按 | 下方 (Prev) | 掃描：取消 / 預設模式：下一個頻道 / 選單：向下 |
| 長按 | 上方 (Next) | 手動模式：儲存頻道 / 預設模式：進入選單 / 選單：確認 |
| 長按 | 下方 (Prev) | 手動 ↔ 預設模式切換 / 選單：離開 |
| 旋轉 | 左側電位器 | 頻率調整 (手動模式下)，選單中選擇頻道 |
| 旋轉 | 右側電位器 | 音量調整 (所有模式) |

### 模式

- **MANUAL 手動模式** — 轉動頻率旋鈕直接選台，長按上方按鈕可儲存當前頻道
- **PRESET 預設模式** — 短按上下按鈕切換已儲存頻道，長按上方按鈕進入選單
- **MENU 選單模式** — 透過選單可選擇頻道、刪除頻道、清空所有頻道、自動掃描

### 自動掃描

掃描時會從 87.5 MHz 到 108.0 MHz 逐一檢查，內建 **Peak Detection 峰值偵測**：
- 相鄰 0.3 MHz 內只保留訊號最強的頻率 (過濾旁波帶 / 鄰頻干擾)
- 掃描後自動排序並儲存
- 掃描中按下方按鈕可取消，取消後自動還原掃描前的頻道清單

### 音量映射

為避免 PAM8403 + 小喇叭在高音量失真，硬體音量僅使用 5 級 (1～5)，
但 UI 顯示仍為 0～15 讓使用者直觀操作，內部自動等份映射。

## 已知設計決策

1. **音量不支援斷電記憶** — 開機預設為靜音，避免爆音
2. **刪除頻道無二次確認** — 進入 Delete Channel 子選單後長按確認即直接刪除
3. **掃描時清空現有頻道** — 自動掃描會從空白頻道清單開始，確保結果無重複 (但可取消還原)
4. **預設頻道清單為台灣 FM 頻率** — 若 NVS 無資料會載入預設值，可依地區修改 `loadPresets()` 中的 `defaultStations[]`

## 疑難排解

| 問題 | 可能原因 | 解決方式 |
|------|----------|----------|
| OLED 不亮 | I2C 位址錯誤或接線鬆脫 | 檢查 0x3C 位址、確認 SDA/SCL 連接 |
| 無聲音 | 音量為 0 或音訊電容未接 | 轉動音量旋鈕、檢查 RRD-102 與 PAM8403 間電容 |
| 掃描不到電台 | RSSI 門檻過高或天線未接 | 降低 `RSSI_THRESHOLD` 或接上 FM 天線 |
| 喇叭雜音 | 電源不乾淨或接地不良 | 檢查所有 GND 是否共接、電源濾波電容 |
